# Recorded Nacht proof of concept

Launch the installed `garden_amd_test` profile with `bash tools/launch_nacht.sh`.

1. Aim down at wide, clear, level floor. Press B to place the comparison pair. Left is the previous mod, right is the AMD-enhanced idle, relative to the placement view.
2. Show movement, a complete blink and the loop boundary. Do not label animation samples as game FPS.
3. Press N to toggle shooting. Both use the same locally corrected shooting animation. Zombies remain active.
4. Demonstrate normal plant controls: H selects, J holds, left-click places, K shovels, L selects None.
5. Show the GPU identification and measured trials in the cloud notebook, with the benchmark limits visible.

Suggested equal presentation time: 45 seconds for AI-assisted game integration and gameplay, then 45 seconds for AMD cloud processing, the comparison and measured results.

The original recorded comparison was accepted by its developer: “it looks perfect and i screen recorded the comparison for the devpost.” Package hashes are in `evidence/`. No recording is included in this repository. Add a hosted demo-video link here when one is available.

Nacht is the submission focus. Other-map development and tests are paused. Do not claim full game decompilation, universal map support, co-op, FSR, 35.4× game FPS, or AMD enhancement of all plant animations.
